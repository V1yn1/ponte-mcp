01
PREPARE O ENDPOINT

URL pública da API

Crie um túnel HTTPS para a API da Ponte e salve a origem pública abaixo. Essa URL será usada na descoberta e na autorização OAuth.

Use apenas a origem, sem /mcp. Salvar a URL não cria um túnel nem publica o serviço.

Exponha apenas a API na porta 4318. O painel da porta 4317 permanece local.

Mantenha a Ponte e o túnel em execução enquanto usar a conexão. Se a origem mudar, salve a nova URL e reconecte o cliente.

02
MCP NATIVO · OAUTH

Adicionar ao ChatGPT

Configure a URL
Salve a URL pública HTTPS para habilitar o OAuth.
URL do servidor MCPConfigure a URL pública primeiro
  1. No ChatGPT, abra Plugins → + → Add custom MCP server. Dê o nome Ponte e cole a URL MCP acima.
  2. Em autenticação, selecione OAuth. O registro do cliente é automático: deixe Client ID e Client Secret sem preencher.
  3. Na página de autorização, confira o código. Neste painel, em Conectar IA, revise a solicitação com o mesmo código e autorize.
  4. Volte ao ChatGPT e selecione @Ponte na conversa para disponibilizar as ferramentas.

A conexão nativa usa OAuth e não pede que você copie uma chave de API.

02
CONECTOR REMOTO · OAUTH

Adicionar ao Claude

Configure a URL
Salve a URL pública HTTPS para habilitar o conector remoto.
URL do servidor MCPConfigure a URL pública primeiro
  1. No Claude, abra Customize → Connectors → Add → Custom → Web. Informe o nome Ponte e cole a URL MCP acima.
  2. Escolha Sign in now e, em OAuth client, Register automatically. A Ponte usa registro automático do cliente.
  3. Compare o código da página de autorização com o pedido em Conectar IA neste painel. Revise os dados e autorize a conexão.
  4. Volte ao Claude e habilite a Ponte nos conectores da conversa. Os projetos e a política de aprovação continuam sendo definidos aqui.

O conector remoto usa OAuth. Para trabalhar localmente, veja as opções Claude Desktop e Claude Code abaixo.

CHATGPT · CONTINUIDADE DA CONVERSA

Avisos de conclusão 0

MCP Events

Quando o ChatGPT se inscreve em uma execução, a Ponte envia um aviso ao terminar. Em uma conversa compatível com eventos, peça para continuar a tarefa quando aquela execução concluir.

Atualize as ferramentas e os eventos do plugin após instalar esta versão. A aprovação automática libera ferramentas; a inscrição em eventos permite retomar a conversa.

“Aviso recebido” confirma a entrega ao cliente. A continuidade da tarefa depende do ChatGPT e das instruções da conversa. Encerrar um aviso não cancela a execução.

GPT ACTIONS · OPENAPI
Conectar com chave de API
No editor de GPT Actions, importe o esquema OpenAPI e configure autenticação API Key, tipo Bearer, com o token de API desta Ponte.
Obtenha o token no terminal, na pasta da Ponte MCP:
node dist/cli.js token api
Actions envia Authorization: Bearer SEU_TOKEN_API. O token de administração é exclusivo deste painel.
