# Ponte MCP — plano de implementação

> **Registro histórico.** Este documento preserva o planejamento da entrega indicada, não instruções para reexecutá-la. Consulte o [índice atual](../../README.md), o [histórico de versões](../../../CHANGELOG.md) e a [validação](../../VALIDACAO.md) para o comportamento e a evidência publicados.

> Execução autorizada pelo pedido de construir o projeto. Tarefas locais reversíveis serão implementadas e verificadas nesta sessão; integração na conta ou no computador do usuário exige configuração nesse ambiente.

**Objetivo:** entregar servidor executável, painel e código completo com integração MCP.

**Arquitetura:** um serviço local compartilhado, duas portas com credenciais independentes e clientes upstream MCP. API REST de trabalhos e fachada MCP usam o mesmo catálogo e a mesma política.

**Stack:** Node.js >=22.12, TypeScript, SDK MCP 1.32.1, Express 5, Zod 3, AJV 8, testes node:test e HTML/CSS/JS sem build de frontend.

**Especificação:** ../specs/2026-10-21-ponte-design.md

## Restrições globais
- Administração em 127.0.0.1:4317; API em 127.0.0.1:4318 por padrão.
- Nenhum token no pacote de distribuição, log ou URL.
- Ferramentas externas não são automaticamente confiáveis.
- Código portátil; nenhuma conexão real ao Studio é presumida.

## Foco de revisão
- Caminhos fora do projeto, symlinks, atalhos de Windows e arquivos sensíveis.
- Reenvio de uma escrita, hash desatualizado e concorrência sobre o mesmo arquivo.
- Aprovação expirada, cancelamento e troca de servidor após revisão.
- Respostas extensas, processos travados, paginação circular e desconexão.
- Tentativa de usar credencial do chat na administração ou de aprovar via MCP.

## Tarefas
- [x] Core: configuração validada, tokens, auditoria, fila e política; testes de estados, idempotência e aprovação. Arquivos src/core/*; interfaces src/types.ts.
- [x] Ferramentas locais: src/tools/local.ts e tests/local.test.ts; exportar createLocalTools(getConfig, stateDir): ToolDefinition[]. Testar filesystem real e processo filho.
- [x] Agregador: src/mcp/hub.ts; exportar McpHub(configs), connectAll, reconnect, replaceConfigs, tools, statuses, close. Testar contra fixtures stdio reais.
- [x] Transporte: src/mcp/server.ts e src/http.ts; MCP com list/call e REST com fila assíncrona. Testar autenticação e chamadas reais com SDK.
- [x] Interface: public/index.html, styles.css e app.js; integrar API administrativa, sem dados fictícios. Verificar navegação, login, criação e aprovação.
- [x] CLI e distribuição: src/cli.ts, modo stdio proxy, instalação Windows e exemplos; criar documentação portuguesa com fontes e limitações verificadas.
- [x] Revisão final: npm run verify, smoke end-to-end, revisão independente, pacote ZIP e persistência do entregável.
